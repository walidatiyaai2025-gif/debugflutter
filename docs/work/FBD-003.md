## Objective

Provide the shared logging baseline required by the desktop application and future searchable log viewer without coupling the Application layer to Serilog.

## Implementation

- Added application-level structured log contracts (`AppLogEntry`, `AppLogLevel`, `IAppLogStore`).
- Added a bounded, thread-safe `InMemoryAppLogStore` for UI consumption.
- Added `AppLogStoreSink` to map Serilog events into the application log model.
- Added DI registration so the concrete in-memory store and its application contract resolve to the same singleton.
- Integrated Serilog with the Generic Host.
- Added daily rolling file logging under `%LOCALAPPDATA%/FlutterBuildDoctor/logs` with 14-file retention.
- Added application enrichment and reduced Microsoft framework noise to Information and above.
- Added startup/shutdown lifecycle log messages.
- Added integration tests for structured property capture, level/timestamp mapping and bounded retention.
- Fixed the Windows compile gate by explicitly importing `System.IO` in the log path helper.
