# FBD-410 — Detect installed Android platforms

Status: DONE pending final-head CI and merge

## Scope

Enumerate locally installed Android platform packages from the validated FBD-407 Android SDK root. This task is filesystem-only: it does not invoke sdkmanager, download packages, accept licenses, or modify the SDK.

## Discovery

- consumes the validated effective Android SDK root from FBD-407
- enumerates `<sdk>/platforms/android-*`
- reads `source.properties` when available
- parses `AndroidVersion.ApiLevel`, `AndroidVersion.CodeName`, and `Pkg.Revision`
- falls back to a numeric `android-XX` directory suffix when metadata does not expose an API level
- treats metadata API level as authoritative when it conflicts with the directory suffix and preserves the mismatch in evidence
- records `android.jar` and `framework.aidl` presence
- preserves raw `source.properties`

## Readiness semantics

A platform is usable when its API level can be resolved and `android.jar` exists. Preview platforms remain visible through their non-`REL` codename. Partial/broken platform directories are never hidden.

Result states:

- `Succeeded`
- `AndroidSdkRootUnavailable`
- `PlatformsDirectoryMissing`
- `NoPlatformsInstalled`
- `PartialInstallationsOnly`
- `InspectionFailed`

`InstalledApiLevels` contains distinct usable API levels sorted descending.

## Integration

- `IAndroidPlatformDetector` registered as a production singleton
- composes directly from FBD-403 environment evidence through FBD-407 SDK-root detection
- no subprocess execution or environment mutation
- preserves FBD-408 cmdline-tools and FBD-409 ADB detection unchanged

## Coverage

Unit tests cover stable platform metadata, preview/non-numeric package names, numeric directory fallback, metadata/directory mismatch, partial installs missing android.jar, mixed usable/partial installs, missing platforms directory, empty platforms inventory, and invalid SDK roots.

Integration coverage validates the FBD-403 snapshot -> FBD-407 root -> FBD-410 inventory path on a real temporary SDK layout and asserts `ANDROID_SDK_ROOT` / `ANDROID_HOME` process values remain unchanged.
