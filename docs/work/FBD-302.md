# FBD-302 — Validate repository URL

## Status

DONE

## Scope

Validate a user-supplied Git remote URL before clone or network execution. This task intentionally performs local syntax and safety validation only; repository reachability and clone behavior remain in FBD-303.

## Implementation

- Added typed Git repository URL validation contracts in `FlutterBuildDoctor.Git`.
- Supports HTTPS, HTTP, SSH URI, `git://`, and SSH SCP-style remotes such as `git@host:owner/repository.git`.
- Trims outer whitespace and normalizes a trailing slash for URI-style remotes.
- Rejects empty or malformed values with explicit error codes and user-readable reasons.
- Rejects Windows drive paths, UNC paths, relative paths, and rooted local paths because this workflow requires a remote repository URL.
- Rejects unsupported schemes such as `ftp://` and `file://`.
- Requires both a host and repository path.
- Rejects query strings and fragments.
- Rejects embedded HTTP(S) credentials/tokens and SSH passwords so secrets are not carried in repository URLs.
- Added UnitTests project reference to `FlutterBuildDoctor.Git` and comprehensive URL-validation tests.
