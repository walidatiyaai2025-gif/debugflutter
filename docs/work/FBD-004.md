## Confirmed starting point

FBD-002 and FBD-003 are complete: the WPF application starts through Generic Host/DI and has structured Serilog file plus in-app logging. No global dispatcher, AppDomain or unobserved-task exception boundary existed.

## Implementation

- Added application-level exception source, record and reporter contracts.
- Added `AppExceptionReporter` with stable reference IDs and safe user-facing summaries.
- Exception messages are not copied into normal UI text.
- Structured logs capture reference ID, source, exception type, HResult and stack trace without deliberately logging the exception message.
- Added `GlobalExceptionHooks` for WPF dispatcher, AppDomain and unobserved Task exception sources.
- Recoverable dispatcher exceptions are marked handled only after reporting; fatal memory/access/stack exceptions are not marked recoverable.
- Unobserved Task exceptions are marked observed after reporting.
- Added deterministic hook attach/detach around Generic Host startup/shutdown.
- Host startup/shutdown failures are routed to the exception reporter when the host exists, with a minimal startup fallback dialog.
- Bound the shell status bar to `MainWindowViewModel.StatusMessage` so users get a safe reference ID while technical evidence remains in logs.
- Added integration tests for reporter state, safe UI surfacing and critical/terminating classification.
