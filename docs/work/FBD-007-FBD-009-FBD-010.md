## FBD-010 — application version/build identity service

Implemented:
- immutable `ApplicationIdentity` contract;
- singleton `IApplicationIdentityService` / `ApplicationIdentityService`;
- product version from assembly informational/version metadata;
- commit identity only from a validated 7–64 character hexadecimal SHA candidate;
- CI build number only when numeric, otherwise assembly file version fallback;
- short commit projection for UI/logging;
- main window title includes the identity;
- startup log records structured version/build/short-commit evidence;
- integration coverage verifies DI registration, valid metadata parsing and rejection of unsafe environment values.

## Security boundary

The identity service does not enumerate environment variables and does not surface arbitrary environment values. Only named CI identity variables are considered, and commit/build candidates are accepted only after strict format validation.
