# FBD-413 — Detect avdmanager

Status: DONE pending live-main PR CI and merge

## Scope

Detect `avdmanager` availability from the FBD-408 command-line-tools inventory without executing avdmanager or mutating virtual-device state, and expose the validated result through the live Environment Doctor UI.

## Discovery

- consumes FBD-408 command-line-tools candidates directly
- maps `avdmanager.bat`, `.exe`, or portable executable presence under each installation `bin` directory
- preserves command-line-tools revision/layout evidence
- preserves FBD-408 effective/latest/versioned/legacy precedence
- checks all discovered installations for evidence
- never silently promotes a non-effective installation when the effective one is missing avdmanager

## Result states

- `Succeeded`
- `CommandLineToolsUnavailable`
- `AvdManagerMissing`

## Safety boundary

No external process is executed. FBD-413 does not create, delete, list, modify, or launch AVDs.

## Live UI integration

- `IAndroidAvdManagerDetector` registered as a production singleton
- Environment Doctor runs the detector immediately after command-line-tools discovery
- UI shows effective `avdmanager` path, command-line-tools revision and alternate-installation evidence
- Android emulator detection is also surfaced as a dedicated readiness card
- `Devices & Emulators` remains disabled because AVD enumeration, device inventory and launch/lifecycle management are separate unfinished capabilities

## Coverage

Unit tests cover effective availability, broken effective installation with usable alternate and no silent fallback, multiple-installation evidence, and unavailable command-line tools.

Integration coverage validates the full local SDK-root/command-line-tools/avdmanager chain with no process execution. Environment Doctor ViewModel coverage verifies the live UI projection.

## Validation

The original FBD-413 backend lineage passed CI before merge to the integration line. The current `agent/fbd-413-main-ui` branch ports that validated implementation onto `main`; exact PR merged-tree CI must pass before merge.
