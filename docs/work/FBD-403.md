# FBD-403 — Read relevant environment variables

Status: DONE pending final-head CI and merge

## Scope

Capture the Windows environment variables required by downstream Android/Flutter environment discovery without mutating process, user, or machine configuration.

Required variables:

- `PATH`
- `JAVA_HOME`
- `ANDROID_HOME`
- `ANDROID_SDK_ROOT`

## Implementation

- Added immutable typed environment-variable snapshot contracts in `FlutterBuildDoctor.Application`.
- Added `IVariableValueSource` and `SystemVariableValueSource` for read-only Process/User/Machine scope reads.
- Added `IEnvironmentVariableReader` and `EnvironmentVariableReader`.
- Process scope is treated as the effective value inherited by child commands.
- User/Machine values are retained as evidence and are never silently promoted over a missing Process value.
- Missing and unavailable scope reads are explicit and preserve safe error evidence.
- Registered the reader/source in the existing runtime-detection DI graph.
- No writes to PATH, JAVA_HOME, Android variables, registry, or machine/user environment configuration.

## Integration

FBD-403 composes with the completed environment stack:

`FBD-402 PATH discovery -> FBD-403 environment snapshot -> FBD-407 Android SDK root discovery`

It preserves the completed FBD-404 Flutter detector and FBD-406 Java detector unchanged.

## Tests

Unit coverage validates:

- all required variables and scopes

- Process scope as the effective value
- no invented fallback from User/Machine scope

Integration coverage validates:
