# FBD-605 — Parse Gradle wrapper version

Status: IN PROGRESS

## Goal

Read the Gradle wrapper configuration under the effective FBD-601 Flutter project root and expose the configured Gradle distribution version without executing Gradle or mutating the repository.

## Implementation

- added `IGradleWrapperVersionParser` / `GradleWrapperVersionParser` with typed result statuses and distribution kind (`bin` / `all`)
- reads only `android/gradle/wrapper/gradle-wrapper.properties`
- enforces a 256 KiB file-size limit and 2048 logical-line parsing limit
- supports Java-properties separators, escapes, Unicode escapes, and line continuations
- parses the standard `gradle-<version>-bin.zip` / `gradle-<version>-all.zip` archive shape, including prerelease versions
- rejects conflicting duplicate `distributionUrl` values rather than silently selecting one
- rejects project/Android/Gradle/wrapper/properties reparse-point boundaries
- returns explicit missing/invalid/read/unsafe/version-not-found states
- registers the parser as a singleton in production DI

## Security boundary

The result contract intentionally does **not** expose raw `gradle-wrapper.properties` text. A custom `distributionUrl` can contain embedded credentials or query tokens, so only sanitized URL evidence is returned: user-info, query string, and fragment are removed. Error messages do not echo the raw URL. Security regression coverage verifies this contract.

## Safety boundary

FBD-605 is read-only configuration parsing. It does not run `gradlew`, Gradle, Flutter, Dart, Java, or network requests; it does not download distributions or modify wrapper files. AGP and Kotlin plugin parsing remain FBD-606/FBD-607.

## Coverage

Unit coverage includes standard bin/all URLs, prerelease versions, Java-properties continuation, sanitized credential/query evidence, missing properties, missing URL, conflicting duplicate URLs, nonstandard archives, invalid Unicode escape handling, oversized files, and the no-raw-text result contract. Composition coverage verifies the production singleton registration.
