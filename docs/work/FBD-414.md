# FBD-414 — Detect Android Studio installations

Status: DONE pending final-head CI and merge

## Scope

Discover Android Studio installations on Windows as typed environment evidence without launching Studio or changing JetBrains/Android configuration.

## Search boundaries

The detector consumes FBD-401 Windows readiness and searches only bounded known roots:

- Program Files / `Android/Android Studio`
- Program Files (x86) / `Android/Android Studio`
- LocalAppData / `Programs/Android Studio`
- LocalAppData / `JetBrains/Toolbox/apps/AndroidStudio` with bounded recursive depth

Executable discovery prefers `studio64.exe` with `studio.exe` fallback and deduplicates paths case-insensitively.

## Metadata

Per installation, metadata is read in this order:

1. `product-info.json` — name/version/buildNumber/productCode
2. `build.txt` — build identity, with executable file-version fallback for version/product name
3. executable file-version metadata

Malformed product JSON preserves raw metadata and parse error while falling back to other local evidence. Multiple installations remain visible.

## Result states

- `Succeeded`
- `NotWindows`
- `Missing`
- `InspectionFailed`

## Integration

- `IAndroidStudioSearchRootProvider`, `IAndroidStudioInstallationSource`, and `IAndroidStudioDetector` registered as production singletons
- consumes FBD-401 Windows evidence
- no external process execution, Studio launch, registry mutation, or configuration writes

## Coverage

Unit tests cover direct and bounded Toolbox discovery, product-info parsing, malformed JSON with build.txt fallback, multiple installations, missing installs, non-Windows short-circuit, and source failure.

Integration coverage validates production DI and FBD-401 actual Windows evidence feeding a bounded temporary Android Studio installation root.
