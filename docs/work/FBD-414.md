# FBD-414 — Detect Android Studio installations

Status: DONE pending live-main PR CI and merge

## Scope

Detect Android Studio installations on Windows from bounded known installation roots, preserve version/build/source evidence, and surface the result through the live Environment Doctor without launching Android Studio or modifying JetBrains/Android configuration.

## Discovery

- consumes validated FBD-401 Windows environment evidence
- checks Program Files and Program Files (x86) Android Studio roots
- checks LocalAppData Programs
- checks JetBrains Toolbox AndroidStudio roots with bounded recursive depth
- discovers `studio64.exe` with `studio.exe` fallback
- preserves multiple installations instead of collapsing evidence

## Metadata

Priority order:

1. `product-info.json`
2. `build.txt`
3. executable file-version metadata

The detector preserves version, build number, product code, discovery source, metadata source and raw metadata/error evidence when available.

## Result states

- `Succeeded`
- `NotWindows`
- `Missing`
- `InspectionFailed`

## Safety boundary

FBD-414 performs file-system inspection only. It does not launch Android Studio, execute Studio binaries, modify settings, install plugins, change SDK configuration, or mutate JetBrains Toolbox state.

## Live UI integration

- `IAndroidStudioSearchRootProvider`, `IAndroidStudioInstallationSource` and `IAndroidStudioDetector` registered in production DI
- Environment Doctor runs Android Studio detection immediately after Windows environment detection
- UI shows primary version/build, installation count, discovery source, metadata source and executable paths
- all previously promoted Windows/Android environment diagnostics remain intact

## Coverage

Unit tests cover direct and bounded Toolbox discovery, product-info parsing, malformed metadata fallback, missing installations, non-Windows behavior and source failure. Integration coverage composes actual Windows evidence with a bounded deterministic search root. Production DI composition is covered.
