# FBD-418 — Refresh environment action

Status: DONE pending live-main PR CI and merge

## Scope

Make the live Environment Doctor refresh action explicitly capture a new immutable environment snapshot without restarting the application and update every dashboard card/readiness counter from the new result.

## UI behavior

- primary action is labeled `Run / Refresh Snapshot`
- the same command supports first capture and repeated refreshes
- cancellation remains available while a scan is active
- progress remains indeterminate while the snapshot is being captured
- last scan timestamp updates after each successful refresh
- readiness counters recalculate after every completed refresh, including second/subsequent runs where `HasScanned` is already true

## Safety

Refresh executes only the already-approved diagnostic/read-only detector graph plus Git readiness. It does not perform repair or machine mutation.

## Coverage

Integration coverage executes `ScanCommand` twice with two different snapshot results and verifies the second result replaces the first dashboard state without recreating the ViewModel or restarting the app.

## Validation

Branch workflow and exact PR merged-tree workflow must both pass before merge to `main`.
