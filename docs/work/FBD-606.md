# FBD-606 — Parse Android Gradle Plugin version

Status: IN PROGRESS

## Goal

Detect an explicit Android Gradle Plugin (AGP) version from the Gradle scripts already identified by FBD-604, supporting both modern plugin-DSL and legacy buildscript/classpath declarations without executing Gradle.

## Implementation

- added `IAndroidGradlePluginVersionParser` with typed status and declaration evidence
- consumes the successful FBD-604 `GradleDslDetectionResult` and preserves script role/path evidence
- supports modern Groovy plugin declarations such as `id 'com.android.application' version '8.x'`
- supports modern Kotlin DSL declarations such as `id("com.android.application") version "8.x"`
- supports legacy `com.android.tools.build:gradle:<version>` buildscript/classpath coordinates
- accepts identical explicit versions from multiple scripts/patterns and preserves every source
- returns `Ambiguous` when explicit declarations conflict instead of choosing one silently
- does not guess dynamic variables or version-catalog aliases when no explicit static version is present
- strips line/block comments before matching so commented-out versions do not become active evidence
- rejects reparse-point script paths and enforces a 512 KiB per-script inspection limit
- registered the parser as a production singleton

## Safety boundary

FBD-606 reads bounded Gradle script text only. It does not execute Gradle/gradlew, evaluate Groovy/Kotlin code, resolve version catalogs, download plugins, modify scripts, or return raw script content. Kotlin plugin parsing remains FBD-607.

## Coverage

Unit coverage includes modern Groovy, modern Kotlin DSL, legacy classpath, commented-out declarations, duplicate same-version evidence, conflicting versions, dynamic/catalog-style versions, and unavailable FBD-604 input. Composition coverage verifies the production singleton registration.
