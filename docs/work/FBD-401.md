# FBD-401 — Detect Windows version/architecture

Status: DONE pending live-main PR CI and merge

## Scope

Capture typed Windows operating-system/runtime identity required by environment diagnostics and Android Studio discovery without invoking external tools or mutating the machine, and expose that evidence through Environment Doctor.

## Evidence

- OS description and full version
- major/minor/build number
- OS architecture and current process architecture
- 64-bit OS/process flags

## Implementation

- `WindowsEnvironmentInfo` and `IWindowsEnvironmentDetector` contracts in Application
- managed `SystemWindowsRuntimeInfoSource`
- `WindowsEnvironmentDetector` with explicit `Succeeded`, `NotWindows`, and `Unavailable` states
- production DI registration
- Environment Doctor Windows card with build, architecture, bitness and raw runtime message

No WMI, PowerShell, registry mutation, external process execution, or environment changes are used.

## Coverage

Unit tests cover Windows x64, ARM64 OS with x64 process, non-Windows evidence, and source failure. Integration coverage validates production DI and the actual Windows runner.

## Validation

The original FBD-401 backend lineage passed CI and was merged to the integration line. The `agent/fbd-401-main-ui` branch ports it onto current `main`; branch-head and exact PR merged-tree CI are required before live merge.
