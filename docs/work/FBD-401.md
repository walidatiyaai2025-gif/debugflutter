# FBD-401 — Detect Windows version/architecture

Status: DONE pending final-head CI and merge

## Scope

Capture typed Windows operating-system/runtime identity required by environment diagnostics and Android Studio discovery without invoking external tools or mutating the machine.

## Evidence

- OS description
- full OS version string
- major/minor version
- build number when available
- OS architecture
- current process architecture
- 64-bit OS/process flags

## Implementation

- `WindowsEnvironmentInfo` and `IWindowsEnvironmentDetector` contracts in Application
- `IWindowsRuntimeInfoSource` with managed `SystemWindowsRuntimeInfoSource`
- `WindowsEnvironmentDetector` maps the managed runtime evidence to explicit `Succeeded`, `NotWindows`, or `Unavailable` states
- production DI registers the source and detector as singletons

No WMI, PowerShell, registry mutation, external process execution, or environment changes are used.

## Coverage

Unit tests cover normal Windows x64, ARM64 OS with x64 process, non-Windows evidence, and source failure without exception leakage.

Integration coverage validates production DI and the actual Windows GitHub Actions runner against `Environment.OSVersion`, `RuntimeInformation.OSArchitecture`, `RuntimeInformation.ProcessArchitecture`, and 64-bit flags.
