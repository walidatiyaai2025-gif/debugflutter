# FBD-305 — Checkout/switch branch

## Status

DONE

## Scope

Safely switch a cloned Git working tree to a branch selected from the structured FBD-304 branch-discovery results.

## Implementation

- Added typed branch-switch contracts in `FlutterBuildDoctor.Git.Branches`.
- Added `GitBranchSwitcher` backed by the canonical `IProcessRunner`.
- Supports switching to an existing local branch with `git switch -- <branch>`.
- Supports creating a tracking local branch from a selected remote ref with `git switch --track -- <remote>/<branch>`.
- Never uses `--force`, `-f`, or `--discard-changes`; Git is allowed to reject a switch that would overwrite local work.
- Validates repository metadata and the selected `GitBranchInfo` before starting Git.
- Keeps Git Credential Manager and terminal prompts non-interactive per process.
- Preserves process cancellation and timeout semantics.
- Surfaces redacted stderr evidence when Git refuses the switch.
- Verifies the operation after a successful switch by reading `git branch --show-current` and `git rev-parse --verify HEAD`.
- Returns `VerificationFailed` instead of success when Git reports an unexpected branch or invalid HEAD state.
