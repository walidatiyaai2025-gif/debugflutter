# FBD-408 — Detect sdkmanager/cmdline-tools

Status: DONE pending final-head CI and merge

## Scope

Discover installed Android SDK command-line tools and identify the effective Windows `sdkmanager` executable from the validated FBD-407 Android SDK root. This task is read-only and performs no SDK package installation, update, license acceptance, or Java process execution.

## Discovery

- consumes the validated effective Android SDK root from FBD-407
- enumerates `<sdk>/cmdline-tools/*`
- supports the conventional `cmdline-tools/latest` alias
- supports versioned command-line-tools directories
- supports legacy `<sdk>/tools/bin/sdkmanager.bat`
- reads `Pkg.Revision` from `source.properties`
- preserves raw `source.properties` evidence
- discovers `sdkmanager.bat` (and `.exe` where present)

## Effective selection

1. `cmdline-tools/latest` when present
2. otherwise the highest parsed installed `Pkg.Revision`
3. otherwise the legacy `tools` layout

If `latest` exists but is broken or missing sdkmanager, the detector reports the effective installation as broken and preserves older usable installations as evidence; it does not silently promote an older version.

## Result states

- `Succeeded`
- `AndroidSdkRootUnavailable`
- `CommandLineToolsMissing`
- `EffectiveSdkManagerMissing`
- `MetadataInvalid`

## Integration

- `IAndroidCommandLineToolsDetector` registered as a production singleton
- composes directly with FBD-407 root detection
- does not re-read Android environment variables
- does not run `sdkmanager`, `adb`, or Java
- does not modify the SDK or environment

## Coverage

Unit tests cover:

- `latest` precedence with additional versions retained
- highest revision selection when `latest` is absent
- broken `latest` with no silent fallback
- sdkmanager present but revision metadata invalid/missing
- no command-line tools installed
- legacy tools layout
- invalid Android SDK root short-circuit

Integration tests cover:

- production DI singleton composition
- real temporary FBD-407 SDK-root detection feeding FBD-408 command-line-tools detection
