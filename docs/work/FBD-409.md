# FBD-409 — Detect platform-tools/ADB

Status: DONE pending final-head CI and merge

## Scope

Locate Android `platform-tools` and the effective ADB executable under the validated FBD-407 Android SDK root, then execute only a bounded read-only `adb version` probe. This task does not start/restart the ADB server, enumerate devices, install packages, or modify the Android SDK/environment.

## Detection

- consumes FBD-407 validated effective SDK root
- checks `<sdk>/platform-tools`
- locates `adb.exe` (with `adb` fallback for evidence compatibility)
- reads platform-tools `source.properties` when available
- runs only `adb version` through the canonical `IProcessRunner`
- uses a 10-second probe timeout
- preserves cancellation semantics

## Parsed evidence

- ADB protocol version from `Android Debug Bridge version ...`
- platform-tools package/build version from `Version ...`
- falls back to `Pkg.Revision` from platform-tools `source.properties` when the command omits the package version
- optional `Installed as ...` path
- complete raw version output
- raw `source.properties` evidence
- process execution receipt/result

## Result states

- `Succeeded`
- `AndroidSdkRootUnavailable`
- `PlatformToolsMissing`
- `AdbMissing`
- `ProbeFailed`
- `TimedOut`
- `Cancelled`
- `ParseFailed`

## Safety boundary

The detector constructs only `adb version`. It never invokes `start-server`, `kill-server`, `devices`, install, shell, or any state-mutating ADB command.

## Integration

- `IAndroidAdbDetector` registered as a production singleton
- composes with FBD-407 root detection
- uses the canonical FBD-202 process runner
- preserves raw evidence on parse/probe failures

## Coverage

Unit tests cover success parsing, source.properties fallback, missing platform-tools, missing ADB, timeout, process failure, parse failure, and pre-cancellation.

Integration coverage validates production DI and the FBD-407 -> FBD-409 composition with an exact single `version` argument and explicit assertion that no server/device arguments are generated.
