# FBD-603 — Parse pubspec.lock

Status: DONE pending final-head CI and merge

## Scope

Parse the existing `pubspec.lock` under the effective FBD-601 project root. Read-only only: no `flutter pub get`, Dart command, network access, package update, or lockfile mutation.

## Implementation

- Added `IPubspecLockParser` / `PubspecLockParser` and typed parse/result/package contracts.
- Reads only `<effective-root>/pubspec.lock` with an 8 MiB safety limit.
- Rejects reparse-point/symlink lock files instead of following them outside the imported evidence boundary.
- Parses locked package name/version, dependency type, source (`hosted`, `git`, `path`, `sdk`, unknown), selected source metadata, and Dart/Flutter SDK constraints.
- Keeps exact `RawText` as parser source evidence only.
- Redacts credentials plus query/fragment values from structured hosted/Git URL evidence.
- Missing lock files return an explicit status and never trigger dependency resolution.
- Registered `IPubspecLockParser` in production runtime DI.
