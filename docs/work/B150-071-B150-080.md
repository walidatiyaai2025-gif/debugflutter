## Safety

This command layer delegates execution to the existing `IProcessRunner` and never invokes `cmd.exe`, PowerShell, or a shell-concatenated user command. Device IDs, flavors, targets and Dart defines remain separate process arguments.

`clean` is exposed as an explicit command only; this slice does not auto-trigger it as a repair and does not silently mutate project files.

## Tests
