# FBD-416 — Build immutable EnvironmentSnapshot

Status: DONE pending live-main PR CI and merge

## Scope

Compose the validated environment detectors into one immutable, internally consistent snapshot and make the live Environment Doctor scan button consume that snapshot instead of independently re-reading the same environment inputs throughout one scan.

## Snapshot contents

The snapshot captures Windows, environment variables, Flutter, Dart, Java, Android SDK root, command-line tools, ADB, Android platforms, Android build-tools, emulator, avdmanager, Android license readiness and Android Studio, plus capture start/completion timestamps.

## Consistency rules

- environment variables are read once per snapshot
- one effective PATH value is passed to Flutter, Dart and Java discovery
- Dart receives the exact Flutter result from the same capture
- all Android child detectors receive the exact Android SDK root result from the same capture
- avdmanager and license readiness receive the exact command-line-tools result from the same capture
- Android Studio receives the exact Windows result from the same capture
- independent async probes are awaited together while preserving cancellation

## Live UI integration

- `IEnvironmentSnapshotService` registered as a production singleton
- Environment Doctor `Run / Refresh Scan` uses the snapshot service when available
- Git remains scanned separately because Git is outside the FBD-416 environment snapshot contract
- existing direct ViewModel/test construction keeps a legacy detector fallback when no snapshot service is supplied
- every existing UI card is projected from one snapshot in production

## Safety boundary

FBD-416 is orchestration only. It introduces no repair, install, license acceptance, PATH mutation, Android Studio launch, emulator launch, or other machine-changing behavior. The safety boundaries of each child detector remain unchanged.

## Coverage

Integration coverage verifies result identity and dependency reuse across the full snapshot graph, including one PATH source for Flutter/Dart/Java and one Android SDK/command-line-tools result for all dependent detectors. Existing Environment Doctor integration tests continue to cover the fallback projection path.

## Validation

The original FBD-416 backend PR passed exact PR CI and was merged to the integration line. The current `agent/fbd-416-main-ui` branch ports that validated service onto current `main` and makes the live scan button use it. Branch-head and exact PR merged-tree CI are required before live merge.
