# FBD-416 — Build immutable EnvironmentSnapshot

Status: DONE pending final-head CI and merge

## Scope

Compose the already-implemented Windows, environment-variable, Flutter, Dart, Java, Android SDK/tooling/package/emulator/license, and Android Studio detector outputs into one immutable environment snapshot. No new discovery, repair, installation, or environment mutation behavior is introduced.

## Implementation

- Added `EnvironmentSnapshot` as one immutable record containing:
  - Windows environment evidence
  - environment-variable snapshot
  - Flutter SDK result
  - Dart SDK result
  - Java installations result
  - Android SDK root result
  - command-line tools/sdkmanager result
  - ADB/platform-tools result
  - installed Android platforms
  - installed Android build-tools
  - emulator result
  - avdmanager result
  - Android license result
  - Android Studio installations
- Added `IEnvironmentSnapshotService` / `EnvironmentSnapshotService`.
- Registered the snapshot service in production DI.
- Added capture timestamps and `CaptureDuration`.

## Consistency rules

- Environment variables are read once per capture.
- The exact same effective PATH value from that snapshot is supplied to Flutter, Dart, and Java detection.
- Dart consumes the exact Flutter result produced during the same capture.
- Android SDK root detection consumes the exact environment-variable snapshot produced during the same capture.
- command-line tools, ADB, platforms, build-tools, and emulator consume the exact Android SDK result produced during the same capture.
- avdmanager and license detection consume the exact command-line-tools result produced during the same capture.
- Android Studio consumes the exact Windows result produced during the same capture.
- Existing async probes run concurrently where dependency ordering allows it.
- Cancellation is preserved and checked before and after the composed probe set.

## Safety

- No PATH/JAVA_HOME/Android environment variable mutation.
- No Flutter, Dart, Java, Android SDK, license, Android Studio, or Git repair behavior.
- No detector implementation was duplicated or replaced.
- Existing detector result objects and raw evidence remain intact inside the snapshot.

## Coverage

Integration coverage verifies that the snapshot contains the exact detector result objects and that dependency outputs are passed consistently to downstream detectors, including one shared PATH value for Flutter/Dart/Java.
