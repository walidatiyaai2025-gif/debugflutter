# FBD-604 — Detect Groovy vs Kotlin Gradle DSL

Status: DONE pending final PR-head CI and merge

## Goal

Detect the Android Gradle script layout under the effective FBD-601 Flutter project root without executing Gradle and without parsing AGP/Kotlin/SDK/version semantics reserved for later tasks.

## Implementation

- Added one canonical `IGradleDslDetector` / `GradleDslDetector` in `FlutterBuildDoctor.Flutter.ProjectAnalysis`, consuming the typed FBD-601 `FlutterProjectRootResult`.
- Inspects only the standard Android script locations: `settings.gradle(.kts)`, project `build.gradle(.kts)`, and `app/build.gradle(.kts)`.
- Identifies Groovy, Kotlin, or mixed layouts from file extensions only.
- Preserves every discovered safe script path and its role.
- Returns `Ambiguous` rather than silently choosing when both Groovy and Kotlin variants exist for the same role.
- Distinguishes unavailable project root, missing Android directory, missing supported build scripts, ambiguous layout, and inspection failure.
- Permits partial but unambiguous layouts while reporting missing expected role evidence for later analyzers.
- Rejects reparse/symlink Android directories, app directories, and Gradle script files before downstream parsers can consume them.
- Registered the detector as a production singleton in runtime DI.

## Integration correction

Concurrent work initially introduced a second `IGradleDslDetector` implementation in `FlutterBuildDoctor.Android.ProjectAnalysis` that accepted a raw string path. That duplicate implementation and its dedicated unit tests were removed. The retained Flutter ProjectAnalysis implementation is the single source of truth because it consumes FBD-601 typed root evidence directly and is the implementation registered in production DI.

The first PR CI run also exposed one stale `using FlutterBuildDoctor.Android.ProjectAnalysis;` import left after removing the duplicate implementation. The stale import was removed; no runtime behavior changed in that correction.

## Safety boundary

FBD-604 is filesystem presence detection only. It does not read Gradle script contents, execute Gradle/Flutter/Dart/Java, edit files, resolve dependencies, or infer AGP/Kotlin/compile SDK/application ID values. Those remain FBD-605 through FBD-610.

## Coverage

Coverage includes:
