# FBD-405 — Detect Dart SDK + version

Status: DONE pending live-main PR CI and merge

## Scope

Detect Dart SDK installations, link Flutter's bundled Dart to the detected Flutter SDK, preserve PATH conflict evidence, and surface Dart readiness through the live Environment Doctor without modifying PATH or executing Dart.

## Discovery

- consumes the validated FBD-404 Flutter detection result
- checks Flutter's bundled `bin/cache/dart-sdk/bin/dart*`
- uses canonical Windows PATH executable discovery for standalone/PATH Dart candidates
- reads SDK `version` metadata directly
- preserves preferred/shadowed PATH evidence
- reports when PATH-preferred Dart differs from Flutter's bundled Dart
- never changes PATH or chooses a hidden replacement silently

## Result states

- `Succeeded`
- `Missing`
- `MetadataMissing`
- `MetadataInvalid`
- `Cancelled`

## Live UI integration

- `IDartSdkDetector` registered in production DI
- Environment Doctor runs Dart detection immediately after Flutter detection
- UI shows primary Dart version/source and all bundled/PATH candidate evidence
- mismatch and PATH-conflict warnings are surfaced explicitly

## Safety boundary

FBD-405 performs file/PATH discovery only. It does not execute Dart, install SDKs, modify Flutter, or change process/user/machine PATH.

## Coverage

Unit coverage includes bundled Dart, standalone PATH Dart, Flutter/PATH mismatch, multiple PATH candidates/shadowing, missing Dart, missing/invalid version metadata and cancellation. Integration coverage composes Windows PATH discovery with a deterministic Flutter-bundled Dart SDK. Production DI composition is covered.
