# FBD-304 — Fetch branches

## Status

DONE

## Scope

Discover local and remote Git branches for a cloned repository while preserving the existing process-runner, clone, and URL-validation architecture.

## Implementation

- Added typed branch-discovery contracts in `FlutterBuildDoctor.Git.Branches`.
- Added `GitBranchService` backed by the canonical `IProcessRunner`.
- Validates the Git executable path, repository path, `.git` metadata, and timeout before running Git.
- Refreshes remote references with `git fetch --prune --all --no-tags` by default.
- Lists structured local and remote references with `git for-each-ref`.
- Captures branch name, full ref, commit SHA, current-branch state, remote name, and local upstream.
- Filters symbolic remote refs such as `origin/HEAD` so they are not presented as selectable branches.
- Returns cached local/remote refs with `SucceededWithWarning` when an ordinary remote refresh fails.
- Stops immediately and returns explicit status when refresh is cancelled or times out.
- Supports listing cached refs without network refresh when requested.
- Reuses the existing live `ProcessOutputLine` progress channel.
- Disables hidden Git/GCM prompts per process with `GIT_TERMINAL_PROMPT=0` and `GCM_INTERACTIVE=Never`.
