- B150-062: exact/min/max/caret version constraints suitable for common Dart SDK constraints.
- B150-063: Java ↔ Gradle runtime compatibility rule.
- B150-064: Gradle ↔ AGP minimum-version rule with unknown-line warning rather than guessing.

- B150-070: compatibility report aggregation sorted by severity.

## Source snapshots

Compatibility data is deliberately isolated from rule mechanics and tied to documented source snapshots:

- Gradle Java compatibility matrix: https://docs.gradle.org/current/userguide/compatibility.html
- Android Gradle Plugin release compatibility pages: https://developer.android.com/build/releases/
- Android API level minimum AGP table: https://developer.android.com/build/releases/about-agp
- Kotlin Gradle Plugin compatibility table: https://kotlinlang.org/docs/gradle-configure-project.html

Captured Android/Kotlin tables are dated July 2026. Unknown/new version lines produce a warning instead of being treated as compatible by assumption.
