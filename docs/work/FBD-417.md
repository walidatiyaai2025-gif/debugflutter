# FBD-417 — Environment Doctor dashboard UI

Status: DONE pending live-main PR CI and merge

## Scope

Turn the live Environment Doctor into a snapshot-driven readiness dashboard that summarizes the validated environment evidence already promoted to `main` without inventing repair actions for unfinished workflows.

## Dashboard

- overall readiness summary
- ready / attention / total check counters
- 14 readiness checks covering Windows, Android Studio, Git, Flutter, Dart, Java and Android toolchain components
- exact evidence cards remain visible for paths, versions and detector messages
- planned sidebar workflows remain disabled until their real backends exist

## Readiness behavior

The dashboard derives readiness from the same card projection used by the user. It does not hide partial/broken/missing states and recalculates after every completed scan.

## Safety

FBD-417 is presentation/state projection only. It performs no repair, install, PATH mutation, license acceptance, IDE launch, emulator launch or AVD lifecycle action.

## Coverage

Integration coverage runs the live `ScanCommand` against the immutable snapshot path and verifies the dashboard transitions from 14/14 ready to 13/14 when Android license readiness changes to pending. Legacy detector calls are configured to fail if the snapshot path is bypassed.

## Validation

Branch workflow must pass Release Build, full Tests and artifact upload, followed by exact PR merged-tree CI before live merge.
