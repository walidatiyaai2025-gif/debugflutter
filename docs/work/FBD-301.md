# FBD-301 — Detect Git executable/version

## Status

DONE

## Scope

Implement the first Git Repository Manager runtime detector on top of the existing process execution engine without introducing shell-string execution or global environment mutation.

## Implementation

- Added `GitToolDetector` in Infrastructure using the canonical `Application.Environment.IToolDetector` contract.
- Resolves `git.exe` from the current Windows `PATH` using `where.exe` through `IProcessRunner`.
- Executes the resolved Git binary with `--version` through `IProcessRunner`.
- Returns normalized `ToolStatus` with installed state, executable path, parsed version, and explicit failure/timeout messages.
- Added a five-second timeout for both location and version probes.
- Preserves cancellation semantics from the process engine.
- Added runtime DI registration for `IProcessRunner`, the secret redactor, `GitToolDetector`, and `EnvironmentScanService`.
- Wired runtime detection registration into the WPF host composition root.
