# FBD-306 — Pull current branch

## Status

DONE

## Scope

Update the currently checked-out branch from its configured upstream without creating implicit merge or rebase commits and report whether the repository changed.

## Implementation

- Added typed pull contracts in `FlutterBuildDoctor.Git.Branches`.
- Added `GitPullService` backed by the canonical `IProcessRunner`.
- Requires an attached current branch and a configured upstream before pulling.
- Reads the current branch and upstream explicitly before mutation.
- Captures `HEAD` before the pull.
- Uses only `git pull --ff-only`; it does not request merge, rebase, reset, force, or discard behavior.
- Preserves Git/credential prompts as non-interactive per process.
- Preserves timeout and cancellation semantics.
- Surfaces redacted stderr evidence when fast-forward is impossible or Git rejects the update.
- Verifies the current branch did not change after the pull.
- Reads `HEAD` after the pull and returns `UpToDate` when unchanged or `FastForwarded` when the commit changed.
- Returns explicit `DetachedHead`, `NoUpstream`, `TimedOut`, `Cancelled`, `Failed`, and `VerificationFailed` states.
