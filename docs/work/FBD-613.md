# FBD-613 — Parse local.properties SDK / Flutter paths

Status: IN PROGRESS

Issue: #116

## Goal

Parse the tooling-relevant SDK paths from the expected `android/local.properties` file rooted at the successful FBD-601 Flutter project without executing Gradle, Flutter, or Dart.

## Detection rules

- inspect only `<project>/android/local.properties`
- read only the relevant `sdk.dir` and `flutter.sdk` properties into typed evidence
- ignore unrelated keys and never expose their values through the result contract
- support Java-properties comments, `=` / `:` / whitespace separators, escaped backslashes and separators, Unicode `\\uXXXX` escapes, and logical-line continuation
- require configured SDK paths to be fully qualified; no environment-variable or relative-path expansion is guessed
- repeated identical relevant values are accepted with occurrence evidence
- conflicting or mixed malformed duplicate relevant values are ambiguous and no path is selected implicitly
- Android SDK paths are considered structurally plausible when the existing directory contains a recognized SDK marker such as `platform-tools`, `platforms`, `build-tools`, `cmdline-tools`, `tools`, `licenses`, or `emulator`
- Flutter SDK paths are considered structurally plausible when the existing directory contains `bin/flutter` or `bin/flutter.bat`

## Safety boundary

- project root and Android directory reparse/symlink boundaries are rejected
- `local.properties` symlinks/reparse points are not read
- maximum file size: 256 KiB
- no fallback to other files when `local.properties` is missing
- no project mutation
- no raw file content, unknown-property dictionary, passwords, tokens, or unrelated property values are returned
- no SDK executables are invoked

## Coverage

Tests cover valid Android/Flutter SDK paths; Windows/Unix-compatible escaped path syntax; escaped colon/backslashes; Unicode escapes; logical-line continuation; missing keys; empty, relative, nonexistent, and unrecognized-layout paths; repeated identical values; conflicting duplicate values; malformed relevant Unicode escapes; unrelated secret non-exposure; unsuccessful/stale project roots; missing Android directory; missing local.properties; oversized files; local.properties symlink rejection; Android-directory symlink rejection; no-raw/unrelated-properties contract; and singleton DI composition.

## Validation

GitHub Actions on the feature branch and pull request is the authoritative build/test gate because the current local execution environment does not provide the .NET SDK.
