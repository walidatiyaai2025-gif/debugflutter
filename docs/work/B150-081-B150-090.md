# B150-081..090 — Build Orchestration

Status: IN PROGRESS — implementation committed, CI validation pending

## Implemented scope

- B150-081: Debug APK build request/pipeline.
- B150-082: Profile APK build request/pipeline.
- B150-083: Release APK build request/pipeline.
- B150-084: Release AAB build request/pipeline.
- B150-085: flavor argument support as a typed argument pair.
- B150-086: custom Dart target support as a typed argument pair.
- B150-087: artifact discovery checks standard Flutter paths first, then bounded fallback search under project `build/` only.
- B150-088: streaming SHA-256 artifact hash service.
- B150-089: build receipt captures build ID, request, start/end/duration, attempts, result, artifact and hash.
- B150-090: bounded retry policy; default max retry is one and only known transient signatures are eligible.

## Safety

- Build arguments are not shell-concatenated.
- User-provided build option values reject control characters.
- Artifact fallback discovery never searches outside the selected project's `build/` directory.
- Normal compilation failures, cancellation and timeouts do not auto-retry.
- Retry policy is bounded to 0-3 at construction; DI default is one retry.
- A process success without a verified artifact is reported as `ArtifactMissing`, not success.

## Validation gate

Release build and full tests must pass before the stacked PR is considered verified.
